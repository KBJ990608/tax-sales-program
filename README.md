# 세무사 콜드메일 영업 프로그램

> 세무 정보를 받겠다고 **직접 신청한** 사장님들에게, 업체명·대표자가 들어간 맞춤 영업 메일을 보내는 프로그램.
> **모으는 건 자동, 발송 버튼만 사람이** 누릅니다. 그리고 **동의한 분에게만** 보내서 합법적으로 운영합니다.

`Python` · `Streamlit` · `Gmail SMTP` · `Claude API(선택)`

---

## 1. 기획 (왜 만들었나)

### 배경
세무사 영업은 "아무한테나 메일 뿌리기(스팸)"가 아니라, **관심을 표시한 사장님에게 필요한 정보를 제때 보내는 것**이 핵심입니다. 문제는 이걸 손으로 하면 ① 명단이 흩어지고 ② 이름을 일일이 바꿔 넣어야 하고 ③ 같은 사람에게 두 번 보내고 ④ 광고 표기·수신거부 같은 법적 요건을 빠뜨린다는 점입니다.

### 목표
위 4가지를 **한 화면에서 자동으로** 해결한다. 사람이 하는 일은 "발송 버튼 누르기" 하나로 줄인다.

### 타깃
- **보내는 사람**: 개인/소규모 세무사·세무회계 사무소
- **받는 사람**: 세무 정보 수신에 동의한 개인사업자·1인셀러·법인 대표

### 핵심 원칙
| 원칙 | 구현 |
|---|---|
| 동의한 사람에게만 | 신청 시 **수신 동의 필수 체크** — 미동의 시 저장 자체를 거부 |
| 중복 방지 | 이메일 기준 중복 신청 차단 + 같은 캠페인 재발송 차단 |
| 합법성 | 제목 `(광고)` 자동 표기, 본문 하단 **수신거부 안내** 자동 첨부 |
| 사람은 최종 승인만 | 수집·검증·치환은 자동, 실제 발송만 버튼 클릭 |

### 왜 정적 사이트가 아니라 Streamlit 앱인가
단순 랜딩 페이지(HTML)로는 **실제 메일 발송·이력 저장·중복 방지**가 불가능합니다(서버 필요). 그래서 6단계를 하나로 묶은 단일 Streamlit 앱으로 만들었습니다. 로컬에서 바로 열리고, 같은 코드를 Streamlit Cloud에 올리면 24시간 접속됩니다.

## 2. 6단계 흐름

```
① 신청받기 ─▶ ② 명단 관리 ─▶ ③ 템플릿 선택 ─▶ ④ 발송 ─▶ ⑤ 이력 기록
                                                    └────── ⑥ 법적 준수(자동) ─┘
```

1. **신청받기** — 사장님이 업체명·대표자·이메일 입력 + 수신 동의 체크 → `data/구독자.csv` 자동 저장
2. **명단 관리** — 잘못된 이메일·중복·발송완료를 상태 뱃지로 자동 구분, 잘못된 항목 삭제
3. **템플릿 선택** — 고정 메일 5종(환영/개업축하/기장대행/법인결산/연말정산) **또는 AI 맞춤 생성**. `{업체명}`·`{대표자}` 자동 치환
4. **발송** — "🚀 바로 발송" 버튼 → Gmail로 실제 전송(미리보기 제공)
5. **이력 기록** — `data/발송이력.csv`에 저장, 같은 사람에게 같은 메일 두 번 안 감
6. **법적 준수** — 제목 `(광고)` 표기, 수신거부 안내 자동 첨부 (③~④에서 자동 처리)

## 3. 화면 구성 (사이드바 4개 메뉴)

| 화면 | 공개 여부 | 하는 일 |
|---|---|---|
| **① 신청받기** | 🌐 공개 | 사장님 신청 폼 (고객이 쓰는 화면) |
| **② 명단 관리** | 🔒 관리자 | 구독자 표 + 상태(발송대기/발송완료/중복/잘못된 이메일) |
| **③ 메일 보내기** | 🔒 관리자 | Gmail 설정 → 템플릿/AI 선택 → 미리보기 → 발송 |
| **④ 발송 이력** | 🔒 관리자 | 발송 기록 조회 + CSV 다운로드 |

사이드바 하단에 구독자 수·누적 발송 건수가 실시간 표시됩니다.

## 6. 보안

- **관리자 잠금** — ①신청받기만 공개(고객용), ②명단·③발송·④이력은 **관리자 비밀번호** 필요.
  - 로컬: `.streamlit/secrets.toml` 의 `admin_password` (git 제외). 예시: `.streamlit/secrets.toml.example`
  - 배포: Streamlit Cloud → App settings → **Secrets** 에 `admin_password`
  - 비밀번호는 상수시간 비교(`hmac.compare_digest`)로 확인
- **Gmail 앱 비밀번호 미저장** — 발송 시 화면에 입력만, 코드/저장소에 남지 않음
- **AI API 키 미저장** — `anthropic_api_key` 도 secrets/환경변수로만 주입
- **메일 헤더 인젝션 방지** — 업체명·대표자·이메일의 줄바꿈/제어문자 제거 + 길이 제한

### Gmail 앱 비밀번호 발급
일반 비밀번호가 아닌 **앱 비밀번호**가 필요합니다.
구글 계정 → 보안 → 2단계 인증 → 앱 비밀번호 에서 16자리를 발급해 ③ 화면에 입력하세요.

## 7. AI 맞춤 문안 (선택)

③ 메일 보내기에서 "🤖 AI 맞춤 생성"을 고르면, 목적·톤만 적어도 **Claude(Anthropic)** 가 `{업체명}`·`{대표자}` 플레이스홀더가 들어간 메일 문안을 만들어 줍니다. 생성 후 직접 수정도 가능합니다.
- 필요: `anthropic_api_key` (secrets 또는 환경변수 `ANTHROPIC_API_KEY`)
- 모델: `claude-opus-4-8`

## 8. Streamlit Cloud 배포 (24시간 접속)

1. 이 폴더를 GitHub 저장소로 push
2. https://share.streamlit.io → 저장소 연결 → 메인 파일 `app.py` 지정 → **Deploy**
3. App settings → **Secrets** 에 아래 입력
   ```toml
   admin_password = "강력한_비밀번호"
   anthropic_api_key = "sk-ant-..."   # AI 문안 생성 쓸 때만
   ```
> ⚠️ Streamlit Cloud는 파일시스템이 휘발성이라 CSV가 초기화될 수 있습니다. 실서비스로 굳히려면 **Google Sheets 또는 DB 연동**이 필요합니다(로드맵 참고).

## 9. 파일 구조

```
app.py         Streamlit UI (4개 화면)
templates.py   고정 메일 5종 템플릿 + 치환 헬퍼
ai.py          Claude API로 문안 생성 (선택)
mailer.py      Gmail SMTP 발송 + (광고)/수신거부 자동 부착
store.py       CSV 저장/검증/중복·발송여부 판정/입력 sanitize
auth.py        관리자 비밀번호 잠금
data/          구독자.csv, 발송이력.csv (자동 생성, git 제외)
.streamlit/    secrets.toml (비밀번호/키, git 제외)
```

> 기존 정적 HTML 파일(index.html, email_campaign.html, landing.html 등)은 참고용이며, 실제 프로그램은 `app.py` 입니다.
