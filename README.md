# TaxMailer

세무 정보를 받겠다고 직접 신청한 사장님들에게, 업체명·대표자가 들어간 맞춤 영업 메일을 보내는 과정을 하나의 흐름으로 묶은 Streamlit 기반 앱입니다.

**🔗 라이브 앱 — <https://tax-sales-program-29f8n393axir3psbrx3nud.streamlit.app/>**

[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://tax-sales-program-29f8n393axir3psbrx3nud.streamlit.app/)

> 링크를 눌렀을 때 앱 대신 Streamlit 로그인 화면이 뜬다면 앱이 비공개 상태입니다.
> 소유자가 **Settings → Sharing** 을 **Public** 으로 바꾸면 누구나 열 수 있습니다.
> ([배포 절차](#배포-streamlit-community-cloud) 참고)

TaxMailer의 목적은 세무사의 영업 판단을 대체하는 것이 아닙니다. 명단 수집, 형식·이메일 검증, 중복 제거, 이름 치환, 광고 표기와 수신거부 안내 부착처럼 반복적이고 실수가 잦은 업무를 줄여, 세무사가 누구에게 무엇을 제안할지, 문안을 어떻게 다듬을지, 언제 보낼지 같은 판단에 더 집중하도록 돕는 것입니다. 그리고 수신에 동의한 사장님에게만 보내 합법적으로 운영합니다.

## 문제의식

세무사 영업을 실제로 해보면 병목은 꽤 명확합니다.

- 신청자 명단이 엑셀, 메모, 카톡 등에 흩어져 관리가 안 됩니다.
- 메일마다 업체명·대표자 이름을 손으로 바꿔 넣어야 합니다.
- 잘못된 이메일, 중복 신청, 이미 보낸 사람을 매번 눈으로 걸러야 합니다.
- 같은 사람에게 같은 메일을 두 번 보내는 실수가 납니다.
- 제목 (광고) 표기, 수신거부 안내 같은 법적 요건을 빠뜨립니다.

이 앱은 위 병목을 신청 → 관리 → 발송 → 이력의 한 흐름으로 묶은 프로그램입니다.

## 화면 흐름

사이드바 4개 화면으로 구성되어 있습니다. ①만 공개이고, ②③④는 관리자 비밀번호가 있어야 열립니다.

**① 신청받기 (공개)**

- 사장님에게 보여지는 랜딩 화면입니다. 히어로 → 서비스 이용 방법 3단계 → 신청 폼 순서로 이어집니다.
- 첫 화면에 **무료 세무 안내 신청하기** CTA가 있고, 누르면 신청 폼으로 스크롤됩니다.
- 모바일·태블릿·데스크톱에 맞춰 레이아웃이 바뀝니다. (카드 1열 / 2열 / 3열, CTA는 모바일에서 세로 배치)
- 사장님이 업체명·대표자·이메일을 입력하고 수신 동의에 체크합니다.
- 수신 동의는 자동으로 통과되지 않고, 미체크 시 저장 자체를 거부합니다.
- 입력값은 개행·제어문자를 제거해 저장합니다. (메일 헤더 인젝션 방지)
- 저장된 신청자는 `data/구독자.csv`에 누적됩니다. 데모 모드와 무관하게 **항상 실제 데이터로 저장**됩니다.

**② 명단 관리 (관리자)**

- 화면 상단에서 **데모 데이터 불러오기**로 가상 신청자 데이터를 체험할 수 있습니다. (아래 "데모 데이터로 체험하기" 참고)
- 구독자 명단을 표로 보여주고, 각 항목의 상태를 자동으로 구분합니다.
- 상태: 🟢 발송대기 / ✅ 발송완료 / ⚠️ 중복 / ❌ 잘못된 이메일.
- 잘못된 항목은 임의 발송하지 않고, 사람이 확인해 삭제합니다.
- 명단을 CSV로 내려받아 백업할 수 있습니다. (배포 환경 휘발성 대비)

**③ 메일 보내기 (관리자)**

- 발신 Gmail 계정과 앱 비밀번호를 입력합니다. (secrets에 넣어두면 자동으로 채워집니다)
- 고정 템플릿 5종 또는 AI 맞춤 생성 중에서 문안 방식을 고릅니다.
- 아직 안 받은 대상만 자동으로 추려 미리보기를 보여줍니다.
- **미리보기를 확인했다는 체크박스를 켜야 발송 버튼이 활성화됩니다.** 실제 외부 발송은 되돌릴 수 없기 때문입니다.
- 발송 결과(성공 건수, 실패 목록)를 화면에 남깁니다.

**④ 발송 이력 (관리자)**

- 누구에게 언제 어떤 템플릿을 보냈는지 `data/발송이력.csv`에 기록합니다.
- 같은 사람에게 같은 캠페인은 다시 나가지 않습니다.
- 이력을 CSV로 내려받을 수 있습니다.

## 주요 기능

- 수신 동의 필수 신청 폼과 자동 명단 저장
- 이메일 형식 검증, 중복 제거, 발송완료 자동 필터
- 고정 메일 5종 템플릿(환영·개업축하·기장대행·법인결산·연말정산)
- `{업체명}`·`{대표자}` 자동 치환
- AI 맞춤 문안 생성 (Anthropic Claude API, `claude-opus-5`)
- 제목 (광고) 자동 표기, 수신거부 안내 자동 부착
- Gmail SMTP 실제 발송과 발송 이력 기록
- 같은 사람·같은 캠페인 중복 발송 차단
- 관리자 비밀번호 잠금(fail-closed)과 입력값 sanitize
- 발송 전 확인 게이트 — 사람이 미리보기를 확인해야만 발송 가능
- 가상 데이터로 전체 흐름을 체험하는 데모 모드 (실제 발송·실제 데이터와 완전 분리)
- 모바일 대응 반응형 랜딩 (히어로 CTA, 3열 → 2열 → 1열 카드)

## AI 맞춤 문안

③ 메일 보내기에서 "🤖 AI 맞춤 생성"을 고르면, 목적과 톤만 적어도 Claude가 `{업체명}`·`{대표자}` 플레이스홀더가 들어간 재사용 가능한 템플릿(제목+본문)을 만들어 줍니다.

- 생성된 제목·본문은 화면에서 바로 수정할 수 있습니다.
- 실제 발송 전에는 항상 미리보기로 (광고) 표기와 수신거부 문구가 붙은 최종 형태를 확인합니다.
- `anthropic_api_key`(또는 환경변수 `ANTHROPIC_API_KEY`)가 설정되어 있어야 하며, 없으면 생성 버튼이 비활성화되고 안내 문구가 표시됩니다.

## 사람이 판단·승인하는 지점

TaxMailer는 업무를 보조하지만 발송 결정을 대신 내리지 않습니다.

- 신청 저장은 수신 동의가 있어야만 이루어집니다.
- 잘못된 이메일·중복은 표시만 하고, 삭제 여부는 사람이 판단합니다.
- AI/고정 문안은 초안이며, 실제 발송에 쓸지 사람이 검토합니다.
- 발송은 자동으로 실행되지 않고, 사람이 미리보기를 확인하고 체크 후 버튼을 눌러 승인합니다.

```bash
TAXMAILER_DEV=1 .venv/bin/streamlit run app.py     # macOS / Linux
$env:TAXMAILER_DEV=1; .venv\Scripts\streamlit run app.py   # Windows
```

## 설정 (secrets)

프로젝트 루트에 `.streamlit/secrets.toml` 파일을 만들고 아래 값을 넣습니다. (예시는 `.streamlit/secrets.toml.example`)

```toml
# [필수] 관리 화면 잠금. 없으면 ②③④가 아예 열리지 않습니다(fail-closed).
admin_password = "CHANGE_ME"

# [선택] AI 문안 생성용. 비워 두면 AI 버튼만 비활성화되고 앱은 정상 동작합니다.
anthropic_api_key = ""

# [선택] 넣어두면 ③ 메일 보내기 화면에 자동으로 채워집니다.
gmail_address = ""
gmail_app_password = ""
sender_name = ""
```

| 키 | 필수 | 없을 때 동작 |
|---|---|---|
| `admin_password` | ✅ | ②③④ 관리 화면이 열리지 않고 설정 안내만 표시 |
| `anthropic_api_key` | | AI 생성 버튼만 비활성화 + 안내 문구. 고정 템플릿 5종은 그대로 사용 가능 |
| `gmail_address` | | ③ 화면에서 직접 입력 |
| `gmail_app_password` | | ③ 화면에서 직접 입력 (앱은 저장하지 않음) |
| `sender_name` | | ③ 화면에서 직접 입력 |

- `admin_password`: 구독자 명단은 개인정보이고 이 앱은 공개 배포될 수 있으므로, 설정 누락이 명단 공개로 이어지지 않게 막습니다. `CHANGE_ME`를 그대로 쓰지 말고 반드시 직접 만든 값으로 바꾸세요.
- `gmail_app_password`: 구글 계정 → 보안 → 2단계 인증 → 앱 비밀번호에서 발급한 16자리입니다. 구글 계정의 일반 비밀번호가 아닙니다. 앱은 이 값을 어디에도 저장하지 않습니다.
- 각 값은 환경변수(`ADMIN_PASSWORD`, `ANTHROPIC_API_KEY`, `GMAIL_ADDRESS`, `GMAIL_APP_PASSWORD`, `SENDER_NAME`)로 대신할 수도 있습니다.
- `TAXMAILER_DATA_DIR` 환경변수로 CSV 저장 위치를 바꿀 수 있습니다. (기본값: `data/`)

`.streamlit/secrets.toml`과 `data/*.csv`는 `.gitignore`로 제외되어 있습니다. 실제 키와 구독자 명단은 GitHub에 커밋하지 않습니다.

## 배포 (Streamlit Community Cloud)

1. **앱 연결** — [share.streamlit.io](https://share.streamlit.io) 에서 이 저장소를 연결하고 Main file path를 `app.py`, Branch를 `main` 으로 지정합니다.
2. **Secrets 입력** — 앱 선택 → **Settings → Secrets** 에 위 TOML 블록을 그대로 붙여넣고 `admin_password` 값을 바꿉니다. 저장하면 앱이 자동으로 다시 시작합니다.
3. **공개 설정** — 링크를 받은 누구나 열 수 있게 하려면 앱 선택 → **Settings → Sharing** 에서 공개 범위를 **Public**(또는 *Anyone with the link*)으로 바꿉니다.
   비공개 상태면 방문자가 앱 대신 Streamlit 로그인 화면(`share.streamlit.io/-/auth/app`)으로 넘어갑니다.
   공개로 두어도 명단·발송·이력 화면은 `admin_password` 로 따로 잠겨 있어 방문자에게는 ① 신청받기 랜딩만 보입니다.
4. **의존성** — `requirements.txt` 로 자동 설치됩니다. (`requirements-dev.txt` 는 테스트 전용이라 배포에는 쓰이지 않습니다)

배포 환경의 파일시스템은 휘발성이라 재배포 시 `data/*.csv` 가 초기화됩니다. ② 명단 관리의 **명단 CSV 내려받기**로 주기적으로 백업하세요.

## 데모 데이터로 체험하기

앱을 처음 열면 명단과 발송 이력이 비어 있어 기능을 파악하기 어렵습니다. 저장소에 포함된 예시 데이터로 전체 흐름을 바로 체험할 수 있습니다.

```
demo/demo_구독자.csv      가상 신청자 12건
demo/demo_발송이력.csv    가상 발송 이력 3건
```

- **모두 가상 데이터입니다.** 실제 개인정보는 하나도 들어 있지 않습니다.
- 형식이 올바른 주소는 **전부 `example.com`** 입니다. **실제로 수신되지 않는 예약 도메인**(RFC 2606)이라, 설령 발송을 시도해도 실제 사람에게 도달하지 않습니다.
- 나머지 2건(`wrong-email`, `missing@`)은 검증 실패를 보여주기 위해 **일부러 형식을 깨뜨린 값**이라 애초에 발송 대상에서 제외됩니다.
- 정상 대상, 중복 신청, 잘못된 이메일 형식, 이미 발송된 대상, 앞뒤 공백, HTML 특수문자까지 모든 상태가 한 번에 들어 있어 명단 검증 로직을 전부 확인할 수 있습니다.

**사용 방법**

1. ② 명단 관리 화면 상단의 **데모 데이터 불러오기** 버튼을 누릅니다. (버튼을 직접 누를 때만 불러옵니다)
2. 관리 화면 상단에 `DEMO MODE` 배너가, 사이드바에 `현재 모드: 데모` 가 표시됩니다.
3. ②③④ 화면이 모두 데모 데이터를 사용합니다.
4. **데모 종료** 를 누르면 실제 데이터 모드로 돌아갑니다. 다시 불러오면 데모 데이터는 항상 원본 상태로 시작합니다.

**안전장치**

- 데모 모드에서는 **Gmail SMTP 발송이 실행되지 않습니다.** 발송 버튼이 "🧪 데모 발송 실행"으로 바뀌고, 눌러도 발송을 시뮬레이션만 한 뒤 `데모 발송이 완료되었습니다. 실제 이메일은 전송되지 않았습니다.` 라고 알려줍니다. Gmail 계정·앱 비밀번호도 요구하지 않습니다.
- 데모 데이터는 **세션 메모리에만** 존재합니다. `data/구독자.csv` 와 `data/발송이력.csv` 는 읽지도 쓰지도 않으므로 실제 데이터가 오염되거나 데모 데이터와 섞이지 않습니다.
- ① 신청받기(공개 화면)는 데모 모드와 무관하게 항상 실제 데이터에 저장합니다.

## 추천 체험 순서

**데모 데이터로 빠르게 둘러보기**

1. ② 명단 관리에서 **데모 데이터 불러오기** 를 누릅니다.
2. 발송대기 / 발송완료 / 중복 / 잘못된 이메일 상태가 어떻게 구분되는지 봅니다.
3. ③ 메일 보내기에서 고정 템플릿 또는 AI 맞춤 생성을 고릅니다.
4. 업체명·대표자가 치환되고 (광고)·수신거부가 붙은 미리보기를 확인합니다.
5. **🧪 데모 발송 실행** 으로 실제 메일 없이 발송 이력을 만들어 봅니다.
6. ④ 발송 이력에서 기록을 확인하고, ③으로 돌아가 같은 템플릿의 재발송이 차단되는지 봅니다.
7. **데모 종료** 를 눌러 실제 데이터 모드로 돌아갑니다.

**실제 데이터로 확인하기**

1. ① 신청받기에서 업체명·대표자·이메일을 입력하고 수신 동의에 체크한 뒤 신청합니다.
2. 같은 이메일로 다시 신청해 중복이 걸러지는지 확인합니다.
3. 수신 동의를 빼고 신청해 저장이 거부되는지 확인합니다.
4. ② 명단 관리에서 상태 뱃지(🟢 발송대기 등)를 확인합니다.
5. ③ 메일 보내기에서 확인 체크를 켜기 전에는 발송 버튼이 비활성화되어 있는지 확인합니다.
6. (선택) 본인 Gmail 앱 비밀번호로 본인 주소에 1건 발송합니다.
7. ④ 발송 이력에서 기록과 재발송 차단을 확인합니다.

## 프로젝트 구조

```
app.py                 Streamlit UI와 발송 승인 흐름
templates.py           고정 메일 5종 템플릿과 치환 헬퍼
ai.py                  Claude API 기반 문안 생성
mailer.py              Gmail SMTP 발송, (광고)·수신거부 자동 부착
store.py               CSV 저장, 검증, 중복·발송여부 판정, 입력 sanitize
auth.py                관리자 비밀번호 잠금 (fail-closed)
demo.py                데모 데이터 로딩과 데모 세션 상태 관리
tests/                 pytest 테스트
demo/                  공개 예시 데이터 (Git 포함)
  demo_구독자.csv
  demo_발송이력.csv
data/                  구독자.csv, 발송이력.csv (자동 생성, Git 제외)
.streamlit/            config.toml(테마), secrets.toml(비밀번호·키, Git 제외)
requirements.txt       배포용 의존성
requirements-dev.txt   테스트용 의존성
```

저장소에 함께 있는 정적 HTML/CSS/JS 파일(`index.html`, `landing.html`, `email_campaign.html`, `tax_sales_simple.html`, `netlify.toml` 등)과 `email_server.py`, `scrape_leads.py` 는 이 앱 이전에 만든 참고용 레거시이며, 현재 프로그램은 `app.py` 로 실행되는 Streamlit 앱입니다. `app.py` 는 이 파일들을 import 하지 않습니다.

## 한계

- 배포 환경(Streamlit Community Cloud)은 파일시스템이 휘발성이라 CSV가 초기화될 수 있어, 실서비스에는 Google Sheets 또는 DB 연동이 필요합니다.
- 수신거부는 안내 문구만 자동 부착하며, 원클릭 수신거부 처리와 자동 명단 반영은 현재 범위 밖입니다.
- 발송은 한 건씩 순차 처리하므로 대상이 많으면 시간이 걸립니다. 발송 예약·큐잉은 없습니다.
- 오픈율·클릭률 트래킹, A·B 테스트는 아직 없습니다.
- Anthropic API 키가 없거나 사용량 한도 문제가 있으면 AI 문안 생성은 동작하지 않습니다.
- 실제 운영 시 정보통신망법상 사전 동의·(광고) 표기·수신거부 명시 요건과 회사 정책을 반드시 확인해야 합니다.
